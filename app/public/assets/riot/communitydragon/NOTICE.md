# Riot Games assets

These files were exported by CommunityDragon from Riot Games client assets and
are bundled locally so Hexgate Swap does not depend on CommunityDragon at
runtime.

Source: https://www.communitydragon.org/documentation/assets

CommunityDragon and Hexgate Swap are not endorsed by Riot Games. Riot Games and
all associated properties are trademarks or registered trademarks of Riot
Games, Inc.

Run `npm run assets:riot` from the `app` directory to refresh this local copy.
